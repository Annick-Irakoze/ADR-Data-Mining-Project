\# ADR Data Mining Project



\## Overview

This project analyzes Adverse Drug Reaction (ADR) data using R and Shiny.



\## Features

\- Interactive Shiny dashboard

\- Data filtering

\- Apriori association rule mining

\- Data visualization

\- CSV export functionality



\## Technologies Used

\- R

\- Shiny

\- arules

\- dplyr
