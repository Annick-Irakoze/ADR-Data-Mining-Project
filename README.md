\# ADR Data Mining Project



\## Overview



The ADR Data Mining Project is an interactive Shiny application developed in R for analyzing and filtering Adverse Drug Reaction (ADR) data.



The application allows users to view the original dataset, generate a filtered dataset, and export processed data for further analysis. The project demonstrates practical skills in data cleaning, preprocessing, data mining, and dashboard development using R and Shiny.



\---



\## Features



\* Interactive Shiny dashboard

\* View original ADR dataset

\* Filter and preprocess ADR records

\* Generate cleaned datasets

\* Export filtered data to CSV

\* Interactive data tables

\* Association rule mining analysis using support, confidence, and lift metrics

\## Association Rule Mining



This project applies association rule mining techniques to identify relationships between drugs and adverse drug reactions (ADRs).



Metrics calculated include:



\* Support

\* Confidence

\* Lift



These metrics help identify drug-ADR combinations that occur more frequently than expected and may warrant further investigation.
